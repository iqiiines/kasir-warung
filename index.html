Selamat atas pembukaan usaha warung sembakonya. Membuat aplikasi Point of Sale (POS) atau kasir berbasis web sendiri adalah langkah yang sangat tepat untuk memonitor stok barang dan melacak pemasukan dengan akurat. Untuk membangun sistem ini, kita bisa membaginya menjadi tiga komponen utama: antarmuka pengguna (frontend), logika server (backend), dan penyimpanan data (database). Menggunakan stack seperti Node.js atau Python dikombinasikan dengan kontainerisasi seperti Docker akan membuat aplikasi ini sangat mudah dikelola dan dijalankan. Berikut adalah rancangan dasar untuk mulai membangun aplikasi warung sembako Anda: 1. Desain Database (Struktur Data) Anda akan membutuhkan setidaknya tiga tabel untuk mengelola produk dan proses checkout. Berikut adalah contoh skema menggunakan SQL: SQL -- Tabel Produk: Menyimpan daftar barang sembako CREATE TABLE produk ( id SERIAL PRIMARY KEY, nama_barang VARCHAR(100) NOT NULL, harga DECIMAL(10, 2) NOT NULL, stok INT NOT NULL, barcode VARCHAR(50) UNIQUE ); -- Tabel Transaksi: Menyimpan nota/struk setiap kali ada pembelian CREATE TABLE transaksi ( id SERIAL PRIMARY KEY, tanggal TIMESTAMP DEFAULT CURRENT_TIMESTAMP, grand_total DECIMAL(10, 2) NOT NULL ); -- Tabel Detail Transaksi: Menyimpan barang apa saja yang ada di dalam satu keranjang/nota CREATE TABLE detail_transaksi ( id SERIAL PRIMARY KEY, id_transaksi INT REFERENCES transaksi(id), id_produk INT REFERENCES produk(id), kuantitas INT NOT NULL, subtotal DECIMAL(10, 2) NOT NULL ); 2. Logika Hitung Subtotal (Frontend) Pada halaman web kasir, Anda membutuhkan fungsi JavaScript sederhana untuk menghitung subtotal secara real-time saat Anda menambahkan barang ke keranjang belanja. JavaScript // Contoh data keranjang belanja let keranjang = []; // Fungsi untuk menambahkan barang ke keranjang function tambahKeKeranjang(idProduk, nama, harga, qty) { // Cek apakah barang sudah ada di keranjang let item = keranjang.find(i => i.id === idProduk); if (item) { item.qty += qty; item.subtotal = item.qty * item.harga; } else { keranjang.push({ id: idProduk, nama: nama, harga: harga, qty: qty, subtotal: harga * qty }); } updateTampilanKasir(); } // Fungsi untuk menghitung total keseluruhan yang harus dibayar pelanggan function hitungGrandTotal() { let grandTotal = keranjang.reduce((total, item) => total + item.subtotal, 0); console.log("Total yang harus dibayar: Rp", grandTotal); return grandTotal; } 3. Proses Checkout & Kurangi Stok (Backend API) Ketika Anda menekan tombol "Bayar", data keranjang akan dikirim ke server. Server (misalnya menggunakan Node.js/Express atau Python) akan memproses transaksi dan memotong stok barang. JavaScript app.post('/api/checkout', async (req, res) => { const { itemKeranjang } = req.body; // Data dari frontend let grandTotal = 0; try { // Mulai transaksi database (agar data aman jika terjadi error di tengah proses) await db.query('BEGIN'); for (let item of itemKeranjang) { // 1. Hitung ulang subtotal di sisi server (keamanan) const produk = await db.query('SELECT harga, stok FROM produk WHERE id = $1', [item.id]); grandTotal += (produk.harga * item.qty); // 2. Kurangi stok barang di database await db.query('UPDATE produk SET stok = stok - $1 WHERE id = $2', [item.qty, item.id]); } // 3. Simpan data transaksi ke tabel transaksi // 4. Simpan detail barang ke tabel detail_transaksi await db.query('COMMIT'); res.json({ status: "Sukses", pesan: "Pembayaran berhasil, stok telah dikurangi.", grand_total: grandTotal }); } catch (error) { await db.query('ROLLBACK'); res.status(500).json({ status: "Gagal", pesan: "Terjadi kesalahan sistem." }); } }); Sistem di atas adalah fondasi utamanya. Setelah logika dasarnya berjalan, Anda bisa menambahkan fitur lanjutan seperti laporan penjualan harian atau peringatan jika stok beras/minyak sudah menipis. JavaScript const express = require('express'); const app = express(); const port = 3000; // Middleware agar server bisa membaca data JSON dari frontend app.use(express.json()); // Menjadikan folder 'public' sebagai tempat file statis (HTML/CSS) app.use(express.static('public')); // Endpoint API untuk memproses checkout app.post('/api/checkout', (req, res) => { const { items } = req.body; console.log("--- Transaksi Baru Diterima ---"); items.forEach(item => { console.log(`- ${item.nama} (Qty: ${item.qty})`); }); console.log("-------------------------------"); // Di tahap selanjutnya, di sinilah Anda memasukkan perintah SQL UPDATE ke database res.json({ status: "Sukses", pesan: "Pembayaran berhasil dicatat sistem!" }); }); app.listen(port, () => { console.log(`✅ Server Kasir berjalan di port ${port}`); }); 4 Bungkus dengan Docker Simpan sebagai Dockerfile Kita akan menggunakan basis image Node ringan (alpine) untuk menjalankan aplikasi ini tanpa perlu menginstal dependensi Node.js secara langsung di sistem Anda. Berikut adalah langkah-langkah implementasinya melalui terminal: 1 Buat File .gitignore Sebelum menyimpan ke Git, kita perlu memastikan file sistem atau dependensi (seperti folder node_modules jika nantinya Anda menginstal package lokal) tidak ikut terunggah, karena ukurannya besar dan tidak diperlukan di repositori. Di dalam folder kasir-sembako, buat file bernama .gitignore: Bash echo "node_modules/" > .gitignore echo ".DS_Store" >> .gitignore 2 Inisialisasi Git Lokal Jalankan perintah ini di dalam folder kasir-sembako Anda untuk mengubah folder tersebut menjadi repositori Git lokal dan merekam semua file yang sudah kita buat: Bash git init git add . git commit -m "Initial commit: Setup awal UI dan Backend Node.js Kasir" 3 Buat Repositori di GitHub Buka browser dan login ke akun GitHub Anda. Klik tombol New (atau ikon + di pojok kanan atas -> New repository). Isi Repository name dengan kasir-sembako (atau nama lain yang Anda inginkan). Biarkan opsi Public atau Private sesuai kebutuhan Anda. Penting: Jangan centang "Add a README file" atau ".gitignore" karena kita sudah membuatnya secara lokal. Klik Create repository. 4 Hubungkan dan Push ke GitHub Setelah repositori di GitHub terbuat, Anda akan melihat halaman instruksi. Salin URL repositori Anda (misalnya: [https://github.com/username/kasir-sembako.git](https://github.com/username/kasir-sembako.git)). Kembali ke terminal Anda, dan jalankan tiga perintah ini secara berurutan (pastikan mengganti URL dengan URL repositori Anda yang sebenarnya): Bash # Mengubah nama branch utama menjadi 'main' (standar baru GitHub) git branch -M main # Menghubungkan repo lokal ke GitHub git remote add origin https://github.com/username/kasir-sembako.git # Mengirim kode dari komputer Anda ke GitHub git push -u origin main Setelah perintah terakhir selesai, refresh halaman repositori GitHub Anda. Langkah 3: Online-kan secara Gratis dengan GitHub Pages Di halaman repositori GitHub Anda, klik tab ⚙️ "Settings" (Pengaturan) di deretan menu atas. Di menu sebelah kiri, cari dan klik "Pages".
